# Awesome Crocoblock [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

[Crocoblock](https://crocoblock.com/) makes WordPress plugins for building dynamic sites with custom content, listings, filters, forms, and bookings. This list collects standalone add-ons for those plugins.

## JetEngine

- [Adjacent Posts Tools](https://github.com/Crocoblock/jet-engine-adjacent-posts-tags) - Adds next and previous post data to Elementor dynamic tags, JetEngine macros, and listing contexts.
- [Alphabetical Listing Breaks](https://github.com/Crocoblock/jet-engine-break-listing-alphabetically) - Inserts letter headings into a listing that is already sorted alphabetically.
- [Attachment Link Callback](https://github.com/MjHead/jet-engine-attachment-link-callback) - Turns an attachment ID into a file link in the Dynamic Field widget.
- [Calculated Callback](https://github.com/MjHead/jet-engine-calculated-callback) - Adds arithmetic and developer-defined calculation callbacks to the Dynamic Field widget.
- [Calico JetEngine Calendar](https://github.com/CalicoDesignCo/calico-jetengine-calendar) - Displays up to four post type feeds in an Elementor calendar with separate listing templates and date fields.
- [CartFlows Variation Swatches](https://github.com/Crocoblock/jet-engine-cart-flows-swatches) - Displays CartFlows variation swatches inside a listing through the Woo Data widget.
- [CCT Single Page](https://github.com/Crocoblock/jet-engine-cct-single-page) - Creates individual URLs and pages for custom content type items using a Listing Item template.
- [Compact Number Format Callback](https://github.com/mangsinaga/jetengine-number-format-callback) - Formats large numbers with suffixes such as K and M in the Dynamic Field widget.
- [Components Shortcode](https://github.com/Crocoblock/jet-engine-components-shortcode) - Renders a JetEngine component wherever WordPress shortcodes are supported.
- [Custom Contexts](https://github.com/MjHead/jet-engine-custom-contexts) - Lets a dynamic widget or tag use a term from the current post as its context.
- [Custom User Meta Storage](https://github.com/MjHead/jet-engine-custom-user-meta-storage) - Stores selected user meta fields in a custom table through JetEngine's storage feature.
- [Data Stores Cleanup](https://github.com/Crocoblock/jet-engine-data-stores-clear-posts-on-delete) - Removes trashed or deleted posts from JetEngine user-meta data stores.
- [Dynamic Field Widget Add-on](https://github.com/Semonxue/JetEngine-Dynamic-Field-Widget-Addon) - Adds callbacks for image galleries, video lists, and values in nested objects.
- [Dynamic Relation Injector](https://github.com/97NovaClaw/JetEngine-Dynamic-Relation-Injector) - Adds relation selectors to custom content type edit screens so editors can select related records before the initial save.
- [Elementor Repeater Accordions](https://github.com/ShariqKhan2012/Elementor-Repeater-Accordions) - Builds accordion panels from items in a JetEngine repeater field.
- [Elementor Repeater Gallery](https://github.com/ShariqKhan2012/Elementor-Repeater-Gallery) - Builds an Elementor gallery from items in a JetEngine repeater field.
- [Gallery Item Fetcher](https://github.com/hypegg/jetengine-gallery-item-fetcher) - Adds a shortcode to display an individual image from a gallery field.
- [JetEngine Repeater Field Values](https://github.com/rtpHarry/jet-engine-repeater-values) - Exposes repeater values as Elementor dynamic tags for text, images, and galleries.
- [Listing as Filter](https://github.com/Crocoblock/jet-engine-listing-as-filter) - Turns items in one listing into visual filters for another listing using JetSmartFilters.
- [Listing Grid Empty Space](https://github.com/MjHead/jet-engine-listing-fill-empty-space) - Fills unused grid slots with placeholders or expands items to cover empty columns.
- [Marrison Addon JetEngine](https://github.com/marrisonlab/marrison-addon-jetengine) - Adds individually enabled modules for listings, queries, and dynamic fields.
- [Monthly Listing Breaks](https://github.com/MjHead/jet-engine-break-listing-by-months) - Inserts month headings based on the publication date or a date field in a sorted posts query.
- [Monthly Listing Breaks for Multiple Queries](https://github.com/iamHTV/jet-engine-break-listing-by-months-multi-query) - Groups listing items by date and supports multiple queries through matching query ID prefixes.
- [Phone Number Format Callback](https://github.com/Crocoblock/jet-engine-phone-number-format-callback) - Applies a phone number mask to Dynamic Field output.
- [Query Builder for Elementor Pro Loop](https://github.com/MjHead/jet-engine-query-builder-for-epro-loop) - Uses JetEngine posts queries and post-based relations queries as the source for an Elementor Pro Loop Grid.
- [Query Column Sum](https://github.com/MjHead/jet-engine-query-count) - Adds a macro that sums values from a selected column across query results.
- [Related Post Thumbnails and Titles](https://github.com/MjHead/jet-engine-thumbnail-title-from-related-callback) - Displays related post thumbnails and titles through a single Dynamic Field callback.
- [Relations Extended](https://github.com/Crocoblock/jet-engine-relation-hierarchy) - Adds grandparent and grandchild relation queries for filtering listings with JetSmartFilters.
- [SQL Query Paginator](https://github.com/naturalweb-business/jet-sql-paginator) - Paginates custom SQL queries in the database to avoid loading all matching rows into PHP.
- [Sub Query](https://github.com/Crocoblock/jet-engine-sub-query) - Lets a nested listing use an array from its parent item, such as a property returned by a REST API.
- [Trim String Callback](https://github.com/Crocoblock/jet-engine-trim-callback) - Shortens text returned by a Dynamic Field.
- [WooCommerce Purchase Visibility](https://github.com/rtpHarry/jet-engine-dynamic-visibility-woo-user-purchased) - Shows or hides content based on whether the current user bought a specified WooCommerce product.

## JetSmartFilters

- [Advanced Date Range Filter](https://github.com/Crocoblock/jet-smart-filters-advanced-date-filter) - Compares a selected date range with multiple date fields and can check for overlaps or containment.
- [Apply Button Scroll to Top](https://github.com/runthings-dev/runthings-jsf-apply-button-scroll-to-top) - Adds configurable scrolling to the Elementor Apply Button so visitors can return to the filtered results.
- [Astra Compatibility](https://github.com/SargasTM/jet-smart-filters-astra) - Adds support for filtering Astra theme listings.
- [Etch Query Loop Bridge](https://github.com/branislavbudzak/jsf-query-builder-etch-bridge) - Connects the Etch Query Loop block to JetSmartFilters and JetEngine Query Builder.
- [Nested Listing Pagination Fix](https://github.com/rtpHarry/runthings-jetengine-nested-listing-pagination-fix) - Restores the outer listing's pagination when nested JetEngine queries overwrite it in JetSmartFilters Mixed mode.
- [Post Type and Author Filters](https://github.com/MjHead/jet-smart-filters-post-type-and-author) - Filters listings by post type slug or author ID.
- [Search by Post ID](https://github.com/MjHead/jet-smart-filters-search-by-id) - Lets visitors find a post by entering its numeric ID into a Search filter.
- [Search by Post Title](https://github.com/4Fedea/jet-smart-filters-search-by-title) - Adds exact or partial post title matching to the Search filter.
- [Search by Taxonomy Term](https://github.com/developerjillur/jet-smart-filters-search-by-taxonomy-term) - Extends the Search filter to match terms from configured taxonomies.
- [Sticky Posts Fix for Elementor Pro](https://github.com/MjHead/jsf-epro-fix-sticky) - Preserves sticky posts when filters are applied to Elementor Pro listings.

## JetFormBuilder

- [AI Actions for JetFormBuilder](https://github.com/Lonsdale201/ai-for-jetformbuilder) - Adds OpenAI actions and submission events for classifying form data and branching on the result.
- [Attributes for Macros](https://github.com/Crocoblock/jfb-attributes-for-macros) - Adds attribute support to front-end field macros in JetFormBuilder 3 and newer.
- [Brevo Newsletter Action](https://github.com/nextab/jfb-brevo-add-on) - Subscribes users to a Brevo newsletter through a server-side double opt-in workflow.
- [Check Query Action](https://github.com/Crocoblock/jet-form-builder-check-query-action) - Checks whether a JetEngine query returns results and makes matching items or their count available to form actions.
- [Discord Notifications](https://github.com/Lonsdale201/discord-for-jetformbuilder) - Sends a configurable Discord message when a form is submitted.
- [FluentBoards Tasks](https://github.com/Lonsdale201/fluentboards-for-jetformbuilder) - Creates a task in a selected FluentBoards board from form submissions.
- [FluentCRM Subscriptions](https://github.com/Lonsdale201/fluentcrm-subscriptions-for-jetformbuilder) - Adds form actions for subscribing and updating FluentCRM contacts.
- [Form Records Export and Import](https://github.com/DeBelserArne/jetformbuilder-export-import) - Transfers stored submissions between WordPress installations.
- [Google Sheets for JetFormBuilder](https://github.com/Lonsdale201/google-sheet-for-jetformbuilder) - Appends submissions to a spreadsheet using a Google service account.
- [Is Valid Inputs Field](https://github.com/Crocoblock/jfb-is-valid-inputs-field) - Lets a hidden field or conditional block reflect whether the form fields are valid.
- [MarkupMarkdown Integration](https://github.com/muneebgawri/jetformbuilder-markupmarkdown-integration) - Replaces the form's TinyMCE editor with a Markdown editor.
- [Media Storage for JetFormBuilder](https://github.com/Lonsdale201/media-storage-for-jetformbuilder) - Syncs files uploaded through forms to Dropbox, Google Drive, or Cloudflare R2.
- [Update Field](https://github.com/Crocoblock/jet-form-builder-update-field) - Refreshes a field's value or choices when another field changes.
- [ViaCEP Address Autofill](https://github.com/MiguelFaria009/autocep-jetbuilder) - Fills Brazilian address fields after a visitor enters their postal code.
- [WebP Upload](https://github.com/marrisonlab/JFBWU) - Converts JPEG and PNG images to WebP during form uploads.

## JetWooBuilder

- [Cart Dynamic Tags](https://github.com/Crocoblock/jet-woo-cart-dynamic-tags) - Exposes WooCommerce cart totals and item counts as Elementor dynamic tags.
- [Category Custom Product Template](https://github.com/rtpHarry/jet-woo-builder-category-custom-product-template) - Assigns single-product templates by WooCommerce category, with priority when a product belongs to several categories.
- [Custom Add to Cart Icons](https://github.com/UraraReika/jet-woo-builder-custom-add-to-cart-icon) - Adds custom icons to JetWooBuilder add-to-cart controls.
- [Custom Product Badges](https://github.com/UraraReika/jet-woo-builder-custom-product-badges) - Creates and styles product badges for JetWooBuilder widgets.
- [Custom Quantity Selectors](https://github.com/UraraReika/jet-woo-builder-custom-quantity-selectors) - Adds alternative quantity controls to JetWooBuilder product and cart widgets.
- [Products Grid Custom Fields](https://github.com/UraraReika/jet-woo-builder-products-grid-custom-fields) - Adds custom field compatibility to the Products Grid widget through a child-theme template override.
- [Products Grid Load More](https://github.com/UraraReika/jwb-products-grid-load-more) - Adds an AJAX Load More control to the Products Grid widget.
- [Quick Add from Product Grid](https://github.com/barbatjuan/woo-jetwoo-quick-add) - Lets shoppers add products or choose a variation directly from a JetWooBuilder product grid.
- [Single Product Widget Visibility](https://github.com/UraraReika/jet-engine-single-products-widget-custom-visibility-conditions) - Adds custom visibility conditions for widgets in JetWooBuilder single-product templates.

## JetBooking and JetAppointment

- [Adult and Child Slot Counts](https://github.com/MjHead/jet-appointments-adults-children-inputs) - Combines separate adult and child fields to calculate how many appointment slots to book.
- [Pending Booking Expiration Guard](https://github.com/fellipesalazar/jetbooking-expiration-guard) - Releases dates held by expired pending bookings after checking the status of any linked WooCommerce order.
- [Quantity Enabled for JetBooking](https://github.com/breakerh/quantity-enabled-for-jet-booking) - Lets customers book several units of a rental item in one booking.

## JetPopup

- [Popup Current URL Fix](https://github.com/HenryBonney/fix-jetengine-popup-current-url) - Preserves the listing URL in notification emails sent by JetEngine Forms embedded in an AJAX JetPopup.
- [Trigger Popup from Options](https://github.com/MjHead/jet-popup-trigger-from-options) - Uses a switch or another boolean field on a JetEngine options page to control whether a popup opens.
- [Twig Dynamic Popup](https://github.com/Crocoblock/jet-engine-twig-dynamic-popup) - Adds popups with dynamic listing data to Timber and Twig listings.

## JetSearch

- [Related Search Results](https://github.com/Crocoblock/jet-search-related-results) - Includes content linked through JetEngine relations in JetSearch AJAX results.
- [Search Custom Product Attributes](https://github.com/Crocoblock/jet-search-custom-attributes) - Makes manually defined WooCommerce product attributes available to the JetSearch AJAX Search widget.

## JetTabs

- [Hide Empty Items](https://github.com/MjHead/jet-hide-empty-items) - Hides empty JetTabs panels, including panels containing a JetEngine listing with no results.
- [Keep Active Tab](https://github.com/MjHead/jet-tabs-keep-active) - Restores the selected JetTabs tab after a page reload.
