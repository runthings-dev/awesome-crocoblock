# Awesome Crocoblock [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

[Crocoblock](https://crocoblock.com/) makes WordPress plugins for building dynamic sites with custom content, listings, filters, forms, and bookings. This list collects standalone add-ons for those plugins.

## JetEngine

- [Adjacent Posts Tools](https://github.com/Crocoblock/jet-engine-adjacent-posts-tags) - Adds next and previous post data to Elementor dynamic tags, JetEngine macros, and listing contexts.
- [Alphabetical Listing Breaks](https://github.com/Crocoblock/jet-engine-break-listing-alphabetically) - Inserts letter headings into a listing that is already sorted alphabetically.
- [Calculated Callback](https://github.com/MjHead/jet-engine-calculated-callback) - Adds arithmetic and developer-defined calculation callbacks to the Dynamic Field widget.
- [CCT Single Page](https://github.com/Crocoblock/jet-engine-cct-single-page) - Creates individual URLs and pages for custom content type items using a Listing Item template.
- [Components Shortcode](https://github.com/Crocoblock/jet-engine-components-shortcode) - Renders a JetEngine component wherever WordPress shortcodes are supported.
- [Custom Contexts](https://github.com/MjHead/jet-engine-custom-contexts) - Lets a dynamic widget or tag use a term from the current post as its context.
- [Custom User Meta Storage](https://github.com/MjHead/jet-engine-custom-user-meta-storage) - Stores selected user meta fields in a custom table through JetEngine's storage feature.
- [Data Stores Cleanup](https://github.com/Crocoblock/jet-engine-data-stores-clear-posts-on-delete) - Removes trashed or deleted posts from JetEngine user-meta data stores.
- [JetEngine Repeater Field Values](https://github.com/rtpHarry/jet-engine-repeater-values) - Exposes repeater values as Elementor dynamic tags for text, images, and galleries.
- [Listing as Filter](https://github.com/Crocoblock/jet-engine-listing-as-filter) - Turns items in one listing into visual filters for another listing using JetSmartFilters.
- [Listing Grid Empty Space](https://github.com/MjHead/jet-engine-listing-fill-empty-space) - Fills unused grid slots with placeholders or expands items to cover empty columns.
- [Monthly Listing Breaks](https://github.com/MjHead/jet-engine-break-listing-by-months) - Inserts month headings based on the publication date or a date field in a sorted posts query.
- [Query Builder for Elementor Pro Loop](https://github.com/MjHead/jet-engine-query-builder-for-epro-loop) - Uses JetEngine posts queries and post-based relations queries as the source for an Elementor Pro Loop Grid.
- [Query Column Sum](https://github.com/MjHead/jet-engine-query-count) - Adds a macro that sums values from a selected column across query results.
- [Related Post Thumbnails and Titles](https://github.com/MjHead/jet-engine-thumbnail-title-from-related-callback) - Displays related post thumbnails and titles through a single Dynamic Field callback.
- [Relations Extended](https://github.com/Crocoblock/jet-engine-relation-hierarchy) - Adds grandparent and grandchild relation queries for filtering listings with JetSmartFilters.
- [WooCommerce Purchase Visibility](https://github.com/rtpHarry/jet-engine-dynamic-visibility-woo-user-purchased) - Shows or hides content based on whether the current user bought a specified WooCommerce product.

## JetSmartFilters

- [Apply Button Scroll to Top](https://github.com/runthings-dev/runthings-jsf-apply-button-scroll-to-top) - Adds configurable scrolling to the Elementor Apply Button so visitors can return to the filtered results.
- [Etch Query Loop Bridge](https://github.com/branislavbudzak/jsf-query-builder-etch-bridge) - Connects the Etch Query Loop block to JetSmartFilters and JetEngine Query Builder.

## JetFormBuilder

- [Google Sheets for JetFormBuilder](https://github.com/Lonsdale201/google-sheet-for-jetformbuilder) - Appends submissions to a spreadsheet using a Google service account.
- [Update Field](https://github.com/Crocoblock/jet-form-builder-update-field) - Refreshes a field's value or choices when another field changes.

## JetWooBuilder

- [Custom Product Badges](https://github.com/UraraReika/jet-woo-builder-custom-product-badges) - Creates and styles product badges for JetWooBuilder widgets.

## JetBooking and JetAppointment

- [Quantity Enabled for JetBooking](https://github.com/breakerh/quantity-enabled-for-jet-booking) - Lets customers book several units of a rental item in one booking.

## JetSearch

- [Related Search Results](https://github.com/Crocoblock/jet-search-related-results) - Includes content linked through JetEngine relations in JetSearch AJAX results.
