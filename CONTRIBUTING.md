# Contributing

Open an issue to suggest a category or discuss an entry. For a new resource or a correction, open a pull request with one resource per commit.

- Choose standalone add-ons that solve a specific Crocoblock problem. In the pull request, explain who benefits and what you verified.
- Use a primary source with enough documentation to get started. Include important dependencies or limitations in the entry when they affect its use.
- Apply the same standard to your own projects and disclose your involvement in the pull request.
- Place the entry alphabetically in the best-fitting section and follow the format `- [Resource name](URL) - Description.`
- Keep each description on one line. Start with a capital letter and end with a period.
- Run `npx awesome-lint` from the repository root and check that any links you added open the intended resource.
